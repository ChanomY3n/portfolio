# Portfolio — RPG World (ธีมจีนโบราณ)

## เปิดดูเว็บ
ดับเบิลคลิก `index.html` → เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ไฟล์แต่ละตัวทำอะไร

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแผนที่ (Home): อาคาร 4 หลัง + แผงที่เปิดเมื่อกดอาคาร |
| `project.html` | **แม่แบบ**หน้ารายละเอียดผลงาน ใช้หน้าเดียวกับทุกผลงาน เช่น `project.html?id=gistda` |
| `css/style.css` | หน้าตาทั้งหมด (สี ฟอนต์ ขนาด) — สีหลักอยู่บนสุดของไฟล์ |
| `js/data.js` | **ข้อมูลทั้งหมด** (ผลงาน ใบรับรอง ประวัติ) — แก้เนื้อหาที่ไฟล์นี้ไฟล์เดียว |
| `js/main.js` | การทำงานของหน้าแผนที่: ลาก ซูม เปิด/ปิดแผง |
| `js/project.js` | สร้างหน้ารายละเอียดผลงาน (Case study) จาก `data.js` — หัวข้อไหนไม่มีข้อมูลจะซ่อนเอง |
| `js/image-sizes.js` | ขนาดภาพผลงาน (สร้างอัตโนมัติด้วย `tools/build.py` — ไม่ต้องแก้เอง) |
| `tools/build.py` | ตรวจไฟล์ภาพที่อ้างถึง + สร้าง `image-sizes.js` → รัน `python tools/build.py` ทุกครั้งที่เพิ่มภาพผลงาน |
| `images/` | ภาพทั้งหมด (แปลงเป็น .webp ให้ไฟล์เล็กลง จาก 26 MB เหลือราว 1.7 MB) |

## เติมข้อมูลยังไง
1. เปิด `js/data.js`
2. หาคำว่า `TODO` (กด Ctrl+F) — ในแผงหน้าแผนที่ TODO จะแสดงกล่อง **[เดียวมาอัพเดต]** · ในหน้ารายละเอียดผลงาน หัวข้อที่เป็น TODO จะถูกซ่อน
   (รายการที่ต้องเติมของแต่ละผลงาน: `docs/portfolio-content-checklist.md`)
3. แทน `TODO` ด้วยข้อความในเครื่องหมายคำพูด เช่น `role: "Lead UX/UI Designer",`
4. บันทึก แล้วกด F5 ที่เบราว์เซอร์

> ⚠️ ก่อนเผยแพร่จริง ต้องไม่มี `TODO` เหลือ และไม่มี [เดียวมาอัพเดต] บนหน้าเว็บ
